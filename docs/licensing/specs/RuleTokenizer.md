# RuleTokenizer 行为规格

输入一条 Legado 书源规则，输出有序 `RuleStep` 数组。处理顺序固定：

1. 去首尾空白；空串返回空数组。
2. **正则段**：找第一个 `##`，其后按 `##` 切分；第一段为 pattern，第二段为 replacement（缺省空串）。规则主体截断到 `##` 之前。
3. **脚本段**：主体中找 `@js:`（取其后全部为脚本）或 `<js>…</js>`（取中间）；截断到标记之前。只在第 2 步之后的剩余主体里找。
4. **选择器段**：非 XPath 规则按 `@` 切分；XPath 规则（以 `/` 开头）只在末尾 `@` 后是已知属性时才切，避免拆坏 `[@id="x"]`。
5. 逐段生成步骤：
   - 属性词（`text/textnodes/html/href/src/title/content` 或以 `attr(` 开头）→ `.attribute(小写)`
   - 第 0 段：`$.`/`$[` → `.jsonPath`；`/` 开头 → `.xpath`；其余 → `.css`
   - 其余段：`.css`
   - 旧前缀转换：`id.x`→`#x`，`class.x`→`.x`，`tag.x`→`x`
6. 输出顺序：选择器/属性 → 脚本 → 正则。

## 边界
- 写在 `##` 替换段里的 `@js:` 属于替换文本，不被识别为脚本。
- 属性判断不区分大小写，但输出统一小写。
