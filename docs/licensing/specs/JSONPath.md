# JSONPath 行为规格

## 输入
- 路径字符串，首尾空白忽略；前缀 `$.` 或 `$` 可有可无。
- 数据：Foundation 解析出的 `Any`（`[String: Any]` / `[Any]` / 标量）。

## 语法
| 片段 | 含义 |
|---|---|
| `a.b` | 取字典键 |
| `a[0]` / `a[-1]` | 数组下标，负数从尾部数 |
| `a[0:2]` / `a[:2]` / `a[-1:]` | 切片，越界自动夹紧 |
| `a[*]` | 展开数组；结果为一层扁平数组 |
| `$..key` | 深度优先找第一个同名键 |
| `$..key[*]` | 先递归找键，再展开 |

## 结果
- 空路径或仅 `$`：返回根对象。
- 任一步类型不符、下标越界、键不存在：返回 `nil`。
- `[*]` 展开后为空：返回 `nil`（不是空数组）。
- 非法方括号内容（如 `[1:2:3]`、`[abc]`）：返回 `nil`。
