橘阅阅读器支持

本地阅读器 · 不提供书籍内容

如何导入书籍

书架右上角 “+” → 选择 TXT / EPUB / PDF。请只导入你拥有合法使用权的文件。

如何添加 OPDS / Calibre

设置 → OPDS / Calibre 书库 → 添加你自建服务器的地址。互联网地址请使用 HTTPS；局域网地址可使用 HTTP。

阅读进度会丢吗

进度保存在本机。卸载应用会清除数据。可在设置 → WebDAV 云同步里配置你自己的服务器做备份。

为什么没有书源 / 搜索 / 段评

商店版定位是本地阅读器，不内置任何书源或内容服务。

反馈问题

请到 GitHub Issues 提交，附上 iOS 版本、App 版本和复现步骤。
