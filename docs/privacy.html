橘阅阅读器隐私政策

最后更新：2026-10-18

橘阅阅读器是一个本地阅读工具。我们尽量不收集任何个人数据。

1. 我们收集什么

  • 不创建账号，不收集姓名、邮箱、通讯录、位置、广告标识。
  • 不接入分析 SDK、广告 SDK 或跨应用追踪。

2. 数据保存在哪里

  • 书籍文件、阅读进度、书签、标注和设置只保存在你的设备上。
  • 卸载应用会删除这些本地数据。
  • 如你主动使用 WebDAV 备份，备份文件会发送到你填写的服务器。

3. 网络访问

  • 只有你主动添加 OPDS / Calibre 书库或使用 WebDAV 时，应用才连接你填写的服务器。
  • 应用不提供、不搜索、不下载任何书籍内容或第三方书源。

4. 朗读

默认使用系统语音，正文不会上传到我们的服务器。

5. 儿童隐私

应用不面向儿童收集任何数据。

6. 联系方式

如有隐私问题，请通过 GitHub Issues 联系。

本应用不提供书籍内容。请只导入你拥有合法使用权的文件。
