本政策说明本应用如何处理你的信息。一句话结论：**我们不收集你的个人信息，书架和阅读记录都留在你自己的设备上。**

## 一、我们是谁

本应用是一款本地阅读工具。我们不运营内容服务器，也不提供书源、电子书或订阅内容；书架上有什么、能读到什么，取决于你自己导入的书籍、书源与订阅地址。

## 二、我们不收集个人信息

- 没有账号体系：不要求注册、登录、手机号或邮箱。
- 不接入广告、统计、推送、崩溃上报等第三方 SDK。
- 不采集广告标识符（IDFA/IDFV），不做跨应用或跨网站追踪。
- 我们没有任何服务器接收你的书架、阅读进度、书源配置或访问凭据。

## 三、保存在你设备上的数据

| 数据 | 内容 | 存储位置 |
|---|---|---|
| 书架与阅读进度 | 你导入的书籍条目、章节位置、书签、分组 | 应用沙盒（UserDefaults） |
| 书源 / 订阅源配置 | 你导入或编辑的规则 JSON | 应用沙盒（UserDefaults） |
| 阅读设置 | 字体、字号、行距、主题、翻页方式 | 应用沙盒（UserDefaults） |
| WebDAV 连接信息 | 服务器地址、账号、远程目录 | 账号在应用沙盒；**密码存入系统钥匙串（Keychain）** |
| 备份包 | 你手动导出的 zip | 由你选择保存位置（「文件」或你自己的 WebDAV） |
| 运行日志与请求诊断 | 本应用自身产生的排障信息 | 应用沙盒 `Documents/AppLogs` |

上述数据我们无法读取。卸载应用即删除应用沙盒内的全部数据；钥匙串条目随卸载一并清除。

## 四、什么时候会联网

仅在你主动使用下列功能时，本应用才向对应地址发起请求，且**直达你配置的第三方，不经过我们**：

| 功能 | 请求去向 |
|---|---|
| 书源搜索、目录、正文 | 你在书源规则里写的站点 |
| RSS 订阅 | 你添加的 feed 地址 |
| OPDS / Calibre 书库 | 你填写的局域网或公网地址 |
| WebDAV 备份与恢复 | 你填写的 WebDAV 服务器 |
| 在线朗读（HTTP TTS） | 你配置的语音接口 |
| 词典查询 | 你配置的词典接口 |
| 打开书籍详情里的外部站点 | 你点击的那个站点 |

系统内置朗读使用设备自带的语音合成，不联网。第三方站点如何处理你的请求（含 IP 地址、Cookie），适用该第三方自己的隐私政策，我们无法控制也无法代办。

## 五、系统权限

- **本地网络**：仅用于发现并连接同一局域网内的 OPDS / Calibre 书库。不连接局域网书库时不会请求该权限。

本应用不申请相册、通讯录、定位、麦克风、相机等权限。

## 六、日志与诊断

运行日志与请求诊断只写入本机沙盒，用途是排查书源失效。写入前会对账号、密码、Cookie、`Authorization` 等字段逐值替换为占位符；崩溃日志单独存放且不参与滚动裁剪。

除非你主动在设置里导出并自行发送，日志不会离开设备。我们不接收日志。

## 七、儿童

本应用不面向 14 周岁以下儿童单独提供服务，也不收集年龄信息。

## 八、你的权利

- **查看与删除**：在「设置」内可清空书架、书源、日志；卸载应用即删除全部本地数据。
- **更正**：数据由你本人在应用内编辑。
- 由于我们手中没有你的数据副本，不存在向运营者申请查阅、导出或删除的流程。

功能变化导致处理方式改变时，我们会更新本页并修改生效日期；重大变化会在应用内提示。
