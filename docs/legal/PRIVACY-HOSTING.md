# 隐私政策放哪、域名怎么来

政策正文在 `docs/legal/privacy-policy.zh-CN.md`，填掉三处占位即可上线。

## 一、三条路

| 路子 | 花钱 | 拿到 ICP 备案号 | 够 Apple 审核用 | 适用 |
|---|---|---|---|---|
| A. GitHub Pages（`<you>.github.io/juyue-privacy/`） | 0 | 不能 | 能（Apple 只要求公网可访问） | 只上非中国大陆区 |
| B. Cloudflare Pages / Vercel + 自有域名 | 域名 30–80 元/年 | 不能（境外托管无法备案） | 能 | 只上非中国大陆区，想要自己的域名 |
| C. 国内云（腾讯云/阿里云）静态托管或轻量服务器 + 域名 + 个人备案 | 域名 30–80 元/年 + 托管 0–100 元/年 | 能 | 能 | 要上中国大陆区，**唯一可行** |

依据：Apple 文档写明中国大陆上架需有效的 ICP 备案号；工信部《关于开展移动互联网应用程序备案工作的通知》（工信部信管〔2023〕105 号）要求 App 主办者按网站备案方式办理，域名、IP 需符合规定。个人可以备案，一个订单可同时备案一个网站与一个 App，二者可共用同一域名。

## 二、走 C 的具体步骤

1. **买域名**：腾讯云 / 阿里云，实名认证。`.com` 约 60–80 元/年，`.cn` 约 30 元/年。
2. **落托管**：轻量应用服务器（约 60–100 元/年，学生/新用户更便宜）或对象存储静态网站托管。域名必须解析到境内 IP，否则备案不通过。
3. **提交备案**（在云厂商备案控制台一次填完）：
   - 主体：个人，身份证 + 人脸核验
   - 网站：域名、网站名称（如「橘阅说明」）、用途选「其他/信息展示」，内容一栏写「App 隐私政策与应用说明」
   - App：名称「橘阅阅读器」、平台 iOS、Bundle ID `com.factorcitrus.juyue.reader`、域名同网站
   - 个人备案不得含论坛、直播、新闻、出版类内容；纯政策页 + 应用介绍没有问题
4. **等管局审核**：通常 1–20 个工作日，期间域名不能换解析。
5. **拿到备案号**：填进 App Store Connect「App 信息 → 中国大陆 → ICP 备案号」，Apple 会与 MIIT 数据比对，填错会以「备案号无效」卡住。
6. **把政策页放上去**：`https://{{域名}}/privacy/`，页脚写备案号并链到 `beian.miit.gov.cn`。

## 三、App Store Connect 的隐私问卷

按当前代码的实际情况填：

- **数据收集**：Data Not Collected（不收集）。书架、书源、进度、日志都只在本机；网络请求由用户配置、直达第三方，不经过开发者。
- **追踪**：No。
- **隐私政策 URL**：`https://{{域名}}/privacy/`
- 若后续接入任何统计/崩溃 SDK，这一栏必须重填——审核会因为「声明与实际不符」直接打回。

## 四、审核备注草稿（可粘贴）

> 本应用是本地阅读工具，不提供内容服务，也不运营账号体系。
>
> 网络用途逐条如下：
> 1. 书源 / RSS / OPDS：由用户自行添加地址，App 直接请求该地址获取目录与正文，不经过我们的服务器；
> 2. WebDAV：用于用户自建服务器的备份与恢复，凭据由用户填写，密码存于系统钥匙串；
> 3. 在线朗读（HTTP TTS）：请求用户自行配置的语音接口；
> 4. 本地网络权限：仅用于连接局域网内的 OPDS / Calibre 书库。
>
> ATS 中的 `NSAllowsArbitraryLoadsInWebContent` 仅作用于这些用户自定义地址的网页登录流程（部分书源站点仍为 http），不用于任何自有服务。
>
> 隐私政策：https://{{域名}}/privacy/ 。首次启动会展示隐私政策摘要并要求同意后才发起任何网络请求。

## 五、首启同意页还缺什么

代码里目前没有政策页、没有同意门（`grep 隐私` 只命中日志脱敏）。要补：

1. 首启（或首次进入书架前）弹层：政策摘要 + 「同意并继续」/「不同意（退出）」；
2. 设置 → 关于 里常驻入口，点击用 `SFSafariViewController` 打开 URL；
3. 同意状态存 UserDefaults，版本号变了重新征询；
4. 未同意前不发任何网络请求（书源、RSS、TTS、WebDAV 全部锁住）。
